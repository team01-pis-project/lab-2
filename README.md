---

## Описание проекта

Программа для расчёта показателей программного обеспечения на основе **модели Jelinski-Moranda**.

Модель Jelinski-Moranda — это одна из классических моделей надёжности ПО.

Модель позволяет:

- Оценить общее количество ошибок в ПО;
- Спрогнозировать время до следующего отказа;
- Спланировать ресурсы тестирования, ориентируясь на заданный уровень надёжности.
